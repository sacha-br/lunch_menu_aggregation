# 🍴 Минск Обеды: Агрегатор обеденного меню

Полностью автоматизированный бессерверный агрегатор комплексных обедов (ланчей) в Минске из популярных заведений. Проект работает автономно, собирает данные каждое утро по будням и отображает их на удобном веб-интерфейсе.

👉 **[Смотреть меню на сегодня (https://sacha-br.github.io/lunch_menu_aggregation/)]**

## 🚀 Как это работает
1. **Сбор данных:** Каждый будний день в 10:15 (по Минску) GitHub Actions запускает Python-парсер.
2. **Парсинг:** Скрипт `lunch_parser.py` обходит сайты ресторанов с помощью `BeautifulSoup` и складывает данные в `all_lunch_menus.json`.
3. **Генерация:** Скрипт `html_make.py` берет свежий JSON и собирает статический `index.html`.
4. **Публикация:** Изменения автоматически пушатся в ветку и мгновенно обновляют сайт на GitHub Pages.

## 🏢 Поддерживаемые заведения
* 🍕 **Пицца Темпо** (Обеденное меню)
* 🌾 **Васильки** (Народные обеды)
* 🥩 **Terra Pizza** (Ланч-меню)
* 📦 **EdaMarket** (Корпоративные обеды)

## 🛠️ Стек технологий
* **Language:** Python 3.10
* **Libraries:** `requests`, `beautifulsoup4`
* **Automation:** GitHub Actions (Cron schedule)
* **Hosting:** GitHub Pages (Static HTML/JS/Tailwind CSS)

## 💻 Локальный запуск

Если вы хотите запустить сборщик и генератор локально на своем компьютере:

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com
   cd ИМЯ_РЕПОЗИТОРИЯ
   ```

2. Установите необходимые библиотеки:
   ```bash
   pip install requests beautifulsoup4
   ```

3. Запустите сбор данных и генерацию страницы:
   ```bash
   python lunch_parser.py
   python html_make.py
   ```

4. Откройте появившийся файл `index.html` или `view_menu.html` в любом браузере.

## ⚙️ Структура репозитория
* `.github/workflows/lunch_parser.yml` — конфигурация автозапуска по расписанию.
* `lunch_parser.py` — классы парсеров для каждого сайта.
* `html_make.py` — скрипт сборки HTML-страницы из сырых данных.
* `all_lunch_menus.json` — кэш последних собранных данных (база данных проекта).
